## 換算規則

- 整體評分：目前百分制呈分。內容 /40、表達 /30、結構 /20、標點字體 /10。
- 品第評分：四項均 /10。
- 基礎分 5、6、5、4 → 20、18、10、4 → 總分 52/100。
- 十分制綜合分為 5.2/10，保留 4:3:2:1 權重，不能將四項簡單平均。
- 切換只更改呈分，評語和批註不變、不觸發重新評分。
- 初次進入預設整體評分，其後記住瀏覽器中的選擇。
- 可修改分項分數、展開維度評語、編輯總評、切換圖文與批改信息。「確認修改」僅保存於本機瀏覽器。

## 範圍與素材

本原型沒有連接正式資料。分數是使用者指定的演示案例，並非把參考截圖的 62 分換算成 52 分。作文可見段落參照截圖，其餘段落與維度評語為演示補充。總字數等資訊沿用截圖展示值，不代表節選實際字數。

reference.png 為使用者原截圖；原文圖片節選與黄色評分標識從該圖片提取。側欄等頁外導航僅保留外觀，上一位／下一位停用，未建立其他頁面。

## 參考案例更新

品第分數對應：4 → 中下、5 → 中中（下）、6 → 中中（上）。目前僅使用使用者明確提供的三個對應，其他分數仍可調整與換算，但不推定品第名稱。分項可直接輸入或使用上下微調按鈕。新版案例使用獨立本機保存鍵，保留舊案例資料。

## 2026-10-10：综合品第与分项编辑

品第評分模式：顶部总分结果仅显示品第名称；四个分项保留十分制分数、输入框与微调编辑。整体评分模式仍显示百分制总分和分项。综合品第由4:3:2:1加权总分换算，换算为十分制后四舍五入，再按完整表格映射品第；实际分数不取整。例如52分对应中中（下），58分对应中中（上）。

品第評分分项展示更新：可编辑品第分＋「分」＋对应品第文字，例如「內容：5 分（中中（下））」。分项精确按表格映射，小数无对应项时提示「暫無對應品第」；顶部综合品第继续按加权总分四舍五入映射。

最终品第展示更新：顶部同时显示十分制加权综合分数与品第文字，例如「9.1 分（上中）」。综合分数最多显示四位小数并去掉末尾零；品第名称仍用未进行显示舍入的综合分数四舍五入到整数后查表，分数源值保持不变。

视觉更新：整体评分与最终品第共用黄色花形圆章样式，品第模式保留综合分数和品第文字。
