# 作文评分展示

通用规则见主目录 `规范与流程/`。Vue 3 原型，`npm run dev` 启动，`npm run build` 构建至 `dist`。

默认后台为成绩概览，支持学生排名、品第分布、维度分析及全班 CSV 导出；查看详情进入评分切换与编辑保存。顶部提供后台、网页-学生端和统一 PRD，保留未保存离开保护。

- 学校设置：`#settings`。按学校保存展示方式和换算规则，示例阈值仅供演示。
- 成绩概览：`#overview`
- 学生评分报告：`#detail?student=1`
- 网页-学生端（按本校设置显示等级、品第或百分制总分，分项不显示品第）：`#student`
- 需求文档：`#prd`

评分数据保存在当前浏览器，正式接口及权限尚未接入；需求验收状态保持待验收。
